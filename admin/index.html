PUBLISHING FLOW

작성에서 발행까지

  1. 1
    GitHub로 로그인

    처음 한 번만 로그인하면 다음부터 MYSC 편집실이 바로 열립니다.

  2. 2
    초안 작성

    제목·요약·태그를 채우고 본문에 이미지와 코드를 넣습니다.

  3. 3
    저장하고 검토

    공개 발행을 끈 채 저장하면 변경 이력만 남고 블로그에는 보이지 않습니다.

  4. 4
    공개 발행

    검토 후 공개 발행을 켜고 저장하면 GitHub Pages가 자동 배포합니다.

BEFORE PUBLISH

마지막 30초 점검

  • 제목만 읽어도 다룬 문제가 보이나요?
  • 선택의 이유와 포기한 대안이 있나요?
  • 고객·직원·계약 정보가 이미지에 없나요?
  • 모바일에서도 다이어그램 글자가 읽히나요?
  • 공개 발행 스위치를 확인했나요?

저장 후 반영까지 보통 1–2분 걸립니다. 실패하면 배포 상태를 확인하세요.

TEXT STYLES

드래그하고, 한 번만 눌러요.

문장을 드래그하면 작은 서식 툴바가 나타납니다. 글꼴은 의미에 따라 자동으로 맞춰져 블로그 전체의 인상이 흐트러지지 않아요.
