# Repository Guide

## Design System

Always read `DESIGN.md` before making visual or UI decisions. Font choices, colors, spacing, and the Editorial Ledger direction are defined there. Do not deviate without explicit approval. In QA, flag any implementation that does not match `DESIGN.md`.

## Content Safety

- Never commit credentials, tokens, API keys, internal workbook data, or private links.
- New posts default to `published: false`.
- Use official MYSC brand assets without redrawing or altering the logo.
